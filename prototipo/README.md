# Prototipo funcional

El prototipo del sistema corresponde a la aplicación real de PulseLab desplegada en Firebase Hosting:

https://virtual-beat-91e9e.web.app

Esta versión permite navegar y probar los flujos principales del sistema:

- Inicio de sesión con Google.
- Vista de alumno.
- Resolución de casos clínicos.
- Monitor de signos vitales 2D/3D.
- Retroalimentación y resultados.
- Vista de docente.
- Banco y editor de casos.
- Gestión de usuarios.
- Reportes.

El código fuente del prototipo se encuentra en la carpeta `src/` del repositorio.
